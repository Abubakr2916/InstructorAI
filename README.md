# InstructorAI

InstructorAI is an AI-powered teaching assistant designed to help instructors create assignments and labs, manage deadlines, evaluate student submissions, and upload marks to an educational portal.

## Project Goals
- Generate assignments and lab activities
- Generate questions and evaluation rubrics
- Manage assignment deadlines
- Collect student submissions
- Evaluate submissions using AI and automated methods
- Match submissions with the correct students
- Upload marks to the educational portal
- Provide feedback to students
- Reduce repetitive work for instructors
